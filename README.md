# CBR Squad Indonesia — Next.js + TypeScript

Website statis profil CSI dengan beranda, organisasi interaktif, direktori 10 regional, halaman regional statis, galeri yang siap diisi, dan metadata SEO.

## Menjalankan

```bash
npm install
npm run dev
```

Buka http://localhost:3000.

## Deploy ke Vercel

Push folder project ini ke GitHub, kemudian di Vercel pilih Add New > Project > Import repository > Deploy. Framework Next.js terdeteksi otomatis.

## Catatan sebelum publikasi

- Ganti `public/hero.jpg` dengan foto resmi komunitas yang sudah mendapat izin. Gambar saat ini merupakan visual konsep ilustratif.
- Tambahkan nama, foto, masa jabatan, kontak, dan dokumentasi yang telah disetujui CSI pada `data/community.ts`.
- Gambar hero saat ini merupakan visual konsep ilustratif; ganti dengan foto resmi komunitas yang sudah mendapat izin.
- Malang Raya tidak ditampilkan sebagai regional resmi karena belum terkonfirmasi dalam brief.
